# راوية | Rawiyah

راوية منصة ثقافية ذكية تهدف إلى تقديم التراث والهوية السعودية بأسلوب قصصي تفاعلي ومبسّط، مع الاعتماد على معلومات موثوقة ومصادر واضحة.

تسمح المنصة للمستخدم بطرح سؤال عن موقع تاريخي، شخصية، حدث، أو عنصر تراثي، ثم تقوم راوية بتحليل السؤال، استرجاع المعلومات ذات الصلة من قاعدة البيانات الموثوقة، وصياغة إجابة قصيرة وواضحة يمكن الاستماع إليها صوتيًا أو الانتقال منها إلى رواية تفاعلية أكثر تفصيلًا.

## فكرة المشروع

تركز راوية على جعل الوصول إلى المحتوى الثقافي والتاريخي السعودي أكثر سهولة وتفاعلًا، بدلًا من تقديم المعلومات في شكل نصوص طويلة أو تجربة تقليدية تشبه محركات البحث.

تبدأ التجربة بسؤال بسيط من المستخدم، ثم تنتقل إلى:

- فهم موضوع السؤال.
- استرجاع المعلومات ذات الصلة.
- توليد إجابة مبنية على حقائق موثوقة.
- تحويل الإجابة إلى صوت.
- الانتقال إلى رواية تفاعلية مرتبطة بالموضوع.

## التقنيات المستخدمة

يعتمد المشروع على مجموعة من الأدوات والنماذج المحلية، من بينها:

- Python
- Flask
- HTML / CSS / JavaScript
- ALLaM
- AraBERT
- Transformers
- PyTorch
- llama.cpp
- Text-to-Speech
- JSON كقاعدة بيانات للمحتوى الموثوق

## طريقة عمل راوية

تسير عملية الإجابة بشكل مبسط كالتالي:

1. يكتب المستخدم سؤاله.
2. يتم تحليل نوع السؤال باستخدام AraBERT.
3. يتم البحث داخل بيانات التراث الموثوقة.
4. يتم اختيار السجل الأقرب إلى سؤال المستخدم.
5. تُرسل الحقائق المسترجعة إلى ALLaM لصياغة الإجابة.
6. يتم التحقق من أن الإجابة لا تحتوي على معلومات غير مدعومة.
7. يمكن للمستخدم الاستماع إلى الإجابة أو الانتقال إلى الرواية التفاعلية.
